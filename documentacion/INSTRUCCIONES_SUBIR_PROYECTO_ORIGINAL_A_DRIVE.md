# Proyecto original publicado — carpeta de fusión

Esta carpeta está preparada para recibir el ZIP completo de la versión de Vivienda Nova que está actualmente publicada en la otra cuenta de Manus.

## Qué debe subirse

Subir **un único ZIP completo del proyecto original**, descargado desde la otra cuenta de Manus. El nombre recomendado es:

```text
VIVIENDA_NOVA_ORIGINAL_PUBLICADO_YYYY-MM-DD.zip
```

El ZIP debe incluir el código fuente, `package.json`, `pnpm-lock.yaml`, `drizzle/`, `server/` y `client/src/`. No hace falta subir `node_modules`.

## Qué no se debe hacer

No sustituir el proyecto publicado por el ZIP de actualización sin compararlo. No borrar esta carpeta, no eliminar versiones previas y no aplicar manualmente migraciones sin revisar el historial de base de datos.

## Qué ocurre después

Cuando el ZIP esté subido, comunicar en este chat: **“El original ya está en Drive para fusionar.”** Se comparará con la actualización integral y se devolverá una nueva entrega lista para aplicar que mantenga las funciones exclusivas de la versión publicada.
