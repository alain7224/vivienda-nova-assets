# Usar la versión v4.1

**Archivo vigente:** `VIVIENDA_NOVA_ACTUALIZACION_INTEGRAL_v4_1.zip`.

No apliques los ZIP v3, v3.1, v3.2 ni v4.0 por separado. La v4.1 reúne las mejoras acumuladas y añade el botón flotante de WhatsApp configurable desde el administrador.

Primero se debe leer `GUIA_PARA_MANUS_ORIGINAL_V4_1.md` y después fusionar el ZIP con el proyecto original, ejecutar migraciones, comprobar la compilación y publicar.
