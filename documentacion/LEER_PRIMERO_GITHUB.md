# Leer primero — Vivienda Nova

Esta carpeta contiene una entrega técnica para continuar el proyecto publicado desde otra cuenta de Manus.

## Orden recomendado

1. Lee `GITHUB_ENTREGA_MANIFIESTO.md`.
2. Lee `CONVERSACIONES_VIVIENDA_NOVA.md` para entender lo solicitado por el propietario.
3. Lee `documentacion/GUIA_PARA_MANUS_ORIGINAL_V4_2.md`, `documentacion/GUIA_PARA_MANUS_ORIGINAL_V4_1.md` y el resumen v5.1.
4. Descarga el ZIP completo desde la Release **v5.1-scroll-fichas**.
5. No mezcles ZIP antiguos con v5.1.

## Importante

Los datos de proveedores son internos y no deben aparecer públicamente. La marca pública debe ser Vivienda Nova o la marca elegida en el administrador.

El ZIP no se guarda en el historial Git porque pesa aproximadamente 560 MB; está adjunto a la Release del mismo repositorio.
