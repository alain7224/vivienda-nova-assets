# Usar la versión v3.2

**Archivo vigente:** `VIVIENDA_NOVA_ACTUALIZACION_INTEGRAL_v3_2.zip`.

Las versiones v3 y v3.1 se mantienen solo como historial. Para fusionar o publicar usa exclusivamente **v3.2**, porque incluye todo lo anterior más:

1. `robots.txt` y sitemap XML dinámico que se actualiza al publicar viviendas.
2. Páginas permanentes `/vivienda/slug` con datos estructurados, canónica, galería, características y mapa.
3. Solicitud de reserva privada solo dentro de cada ficha; no hay pagos ni reservas automáticas.
4. Botón de reserva con texto y colores editables desde el administrador.
5. Vista previa autenticada de borradores antes de publicarlos.
6. Mapa opcional del negocio administrable con enlace de inserción de Google Maps.
7. Bloqueo de textos públicos que mencionen la inmobiliaria fuente.
8. Edición de galería completa desde administrador y migración `0014_seo_reservation_settings.sql`.

Aplica primero la guía unificada y ejecuta las comprobaciones indicadas antes de publicar.
